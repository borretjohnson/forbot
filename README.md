# 📸 EXIF Tool Bot

Telegram-бот для извлечения и удаления EXIF-метаданных из фотографий.

## 🚀 Возможности

- **Извлечение EXIF**: модель камеры, дата съёмки, GPS-координаты, параметры съёмки
- **Удаление метаданных**: полная очистка фото от EXIF одним нажатием
- **Красивый вывод**: форматированный ответ с иконками и ссылками
- **Конфиденциальность**: фото не сохраняются на сервере
- **Поддержка HEIC**: фото с iPhone работают без конвертации

## 📋 Требования

- Python 3.10+
- Telegram Bot Token (получить у [@BotFather](https://t.me/BotFather))

## ⚙️ Установка

```bash
# 1. Создай виртуальное окружение
python3 -m venv venv

# 2. Активируй его
source venv/bin/activate

# 3. Установи зависимости
pip install -r requirements.txt
# Установится: pillow, aiogram, pillow-heif (для HEIC с iPhone)

# 4. Открой bot.py и вставь свой токен (строка 32)
TOKEN = "1234567890:AAH..."

# 5. Запусти бота
python bot.py
```

## 🎮 Использование

### Как отправить фото с метаданными:

**⚠️ Важно:** Telegram удаляет EXIF при обычной отправке фото!

**Правильный способ — отправить как файл:**

1. Нажмите 📎 (скрепка) в поле ввода
2. Выберите **«Файл»** (не «Фото»)
3. Выберите нужное фото
4. Отправьте

```
📎 → Файл → Выбрать фото → Отправить
```

### Команды бота:

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота, приветствие |
| `/help`  | Справка по использованию |

### Как это работает:

1. Отправьте фото **как файл (документ)**
2. Бот извлечёт EXIF-метаданные:
   - 📷 Камера (Make/Model)
   - 📅 Дата и время съёмки
   - 📍 GPS-координаты + ссылка на Google Maps
   - ⚙️ Параметры: выдержка, диафрагма, ISO, фокусное расстояние
3. Нажмите **«🗑️ Удалить метаданные»** — получите чистое фото

## 🔧 Настройки

### Таймаут загрузки
В `bot.py` (строка 44) можно изменить таймаут:
```python
bot = Bot(token=TOKEN, timeout=60)  # 60 секунд
```

### Логирование
Логи выводятся в консоль. Для сохранения в файл добавьте:
```python
logging.basicConfig(
    level=logging.INFO,
    format="%(asctime)s | %(levelname)-8s | %(name)s:%(lineno)d | %(message)s",
    handlers=[
        logging.FileHandler("bot.log"),
        logging.StreamHandler()
    ]
)
```

## 🛡️ Безопасность

- Бот не хранит фотографии пользователей
- Все временные файлы удаляются сразу после обработки
- Используется безопасная загрузка через aiogram
